This project is an infrastructure-independent emergency messaging system designed for disaster scenarios where cellular networks and Wi-Fi are destroyed. It combines mobile application development with embedded systems engineering to create a localized communication lifeline.
The architecture relies on a hybrid pipeline: a Kotlin-based Android application captures high-accuracy GPS coordinates and manual distress messages, which are transmitted via Bluetooth Low Energy (BLE) to a custom-programmed ESP32 microcontroller. The ESP32 acts as a hardware bridge, broadcasting the serialized payload over a 865 MHz LoRa (Long Range) RF network to neighboring receiver nodes, enabling decentralized, mesh-style SOS routing without reliance on traditional internet service providers.
